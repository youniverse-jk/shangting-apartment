# 尚庭公寓（Shangting Apartment）

基于 Spring Boot 3 + MyBatis-Plus + MySQL + Redis 开发的前后端分离公寓租赁管理平台。

## 1. 项目简介

尚庭公寓是一个面向公寓租赁业务的 Java Web 项目，分为**后台管理系统**和**移动端用户系统**。

- **后台管理系统**：面向平台管理员，实现公寓管理、房间管理、租约管理、看房预约管理、平台用户管理等功能。
- **移动端用户系统**：面向租房用户，提供房源检索、公寓详情查看、看房预约、租约管理和浏览历史等功能。

项目采用前后端分离架构，后端基于 Spring Boot 构建 RESTful API，使用 MyBatis-Plus 操作 MySQL 数据库，通过 Redis 存储临时业务数据，并使用 MinIO 管理房源图片。

项目最初基于尚硅谷《尚庭公寓》课程进行开发，在完成基础功能后，将继续围绕性能优化、并发控制、消息队列、权限管理和工程化部署进行自主扩展。

## 4. 项目架构

项目采用 Maven 多模块管理。

```text
lease
├── common                  # 公共配置、工具类、统一响应
├── model                   # 数据库实体、业务枚举
├── web
│   ├── web-admin           # 后台管理 API
│   │   ├── controller
│   │   ├── service
│   │   │   └── impl
│   │   ├── mapper
│   │   └── vo
│   └── web-app             # 移动端 API
│       ├── controller
│       ├── service
│       │   └── impl
│       ├── mapper
│       └── vo
└── pom.xml
```

### 三层架构

**Controller 层**

- 接收和校验前端参数
- 调用 Service 层
- 封装统一响应结果

**Service 层**

- 处理业务逻辑
- 校验业务状态与规则
- 协调多个 Mapper
- 控制数据库事务

**Mapper 层**

- 使用 MyBatis-Plus 完成基础 CRUD
- 使用自定义 XML SQL 处理复杂查询
- 使用 resultMap 完成多表关联结果映射

## 5. 核心业务设计

### 5.1 公寓和房间管理

公寓和房间信息由多张关联表组成，例如房源与图片、标签、配套设施和支付方式之间的关系。

在新增或修改房源时，需要保存主表以及关联表中的数据。

在查询房源详情时，通过多表查询及 MyBatis `resultMap` 映射，将关联信息封装到 VO 对象中返回前端。

### 5.2 登录认证

后台管理端基于 JWT 实现登录认证。

基本流程：

1. 用户提交登录信息
2. 后端验证账号、密码及验证码
3. 验证通过后生成 JWT
4. 前端在后续请求中携带 Token
5. 后端拦截器验证 Token
6. 验证成功后放行请求

Redis 用于保存验证码等具有有效期的临时数据。

### 5.3 租约状态管理

租约包含多个业务状态：

- 签约待确认
- 已签约
- 已取消
- 已到期
- 退租待确认
- 已退租
- 续约待确认

租约业务通过状态字段描述签约、续约、退租等流程，后续将进一步加强状态流转校验和并发控制。

### 5.4 图片管理

项目使用 MinIO 对象存储服务保存公寓和房间图片。

图片上传成功后，将对象访问地址关联至相应业务数据，供前端页面展示。

## 6. 项目运行

### 环境要求

- JDK 17
- Maven
- MySQL
- Redis
- MinIO
- Node.js（前端项目运行时需要）

### 启动流程

1. 创建 MySQL 数据库 `lease`，导入项目 SQL 初始化脚本。
2. 启动 MySQL、Redis 和 MinIO 服务。
3. 配置后端模块中的 `application.yml`，填写数据库、Redis 和 MinIO 连接信息。
4. 启动 `web-admin` 后端服务。
5. 启动 `web-app` 后端服务。
6. 启动对应前端工程，访问后台管理端或移动端页面。

接口文档（以本地实际端口为准）：

```text
http://localhost:8080/doc.html
```

注意：不要将数据库密码、JWT 密钥、MinIO Access Key 和 Secret Key 等敏感配置提交到公开仓库。
